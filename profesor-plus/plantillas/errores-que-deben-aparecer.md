# Errores útiles

1. Presenta una afirmación creíble.
2. Deja que voten.
3. Pide justificación.
4. Muestra dron, mapa, etiqueta o fuente.
5. Formula la regla correcta.
6. Cambia una variable y vuelve a preguntar.

Errores transversales:
- Dron = UAS.
- Operador = piloto.
- Peso real = MTOM.
- A1 permite cualquier sobrevuelo.
- Terreno propio permite volar.
- Geoconsciencia = autorización.
- 120 m siempre desde el despegue.
- Captura antigua = vigente.
